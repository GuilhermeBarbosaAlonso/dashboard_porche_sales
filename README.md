# Porsche Sales Dashboard

Dashboard interativo desenvolvido em **HTML, CSS e JavaScript** para análise de vendas da Porsche. O projeto transforma dados brutos em informações estratégicas, permitindo explorar indicadores de desempenho e responder perguntas de negócio de forma rápida e intuitiva.

## Funcionalidades

- 📊 KPIs de vendas, faturamento e ticket médio;
- 🚗 Filtros dinâmicos por modelo, ano, cidade e método de pagamento;
- 📈 Visualizações interativas utilizando HTML Canvas;
- 💡 Insights automáticos sobre os modelos mais vendidos, desempenho por cidade e tendências de vendas.

## Objetivo

Demonstrar a aplicação de conceitos de **Business Intelligence**, **Análise de Dados** e **Desenvolvimento Web** na construção de um dashboard interativo voltado ao suporte à tomada de decisão baseada em dados.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- HTML Canvas

## IA como ferramenta de apoio

Durante o desenvolvimento deste projeto, utilizei o **ChatGPT (OpenAI)** como ferramenta de apoio para acelerar o processo de prototipação, estruturação do código, refinamento da interface e documentação.
